# day_todo

- 一个简单的待办事项应用，支持用户登录、创建任务、分类管理等功能
- 使用 Next.js 14 + TypeScript + Prisma + MySQL 构建

## 功能特性
- 用户注册与登录（支持游客模式）
- 任务创建、编辑、删除、完成
- 任务分类管理
- 日历视图查看当天任务
- 数据持久化存储

## 技术栈
- Next.js 14 (App Router)
- TypeScript
- Prisma ORM
- MySQL
- Tailwind CSS
- shadcn/ui
- Lucide React
- Next.js App Router
- React Server Components
- Zustand 状态管理
- React Query (可选，用于数据获取)
- ESLint + Prettier 代码规范
